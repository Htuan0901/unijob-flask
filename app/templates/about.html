Về UniJob

UniJob là nền tảng hai chiều kết nối sinh viên tìm việc làm thêm với nhà tuyển dụng. Luồng nghiệp vụ: đăng tin → ứng tuyển → duyệt → hoàn thành → đánh giá hai chiều.

Công nghệ
  • Flask (application factory, blueprint), Jinja2 + Bootstrap 5, Flask-WTF (CSRF, validator)
  • Flask-SQLAlchemy + Flask-Migrate (SQLite/MySQL/PostgreSQL), Flask-Login, Flask-Mail (gửi trong luồng nền)
  • Lập trình mạng: REST API JSON + token, urllib gọi API tỷ giá, bản đồ OpenStreetMap, RSS (XML), LLM
  • Dữ liệu: gợi ý việc làm TF-IDF, phân loại ngành Naive Bayes, thống kê lương VietJobs, biểu đồ Matplotlib
